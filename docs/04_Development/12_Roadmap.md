
# Roadmap

Version: 1.0

## Vision

Develop Mood Pickup as a production-ready ordering platform for Mood Dushanbe, with a stable MVP first and room for future expansion.

---

# Phase 1 — MVP

Implemented through Sprint 3.5: customer authentication, product catalog and
search, interactive configuration, an anonymous device-local persistent cart,
menu administration, media, and audit foundation. Checkout, authoritative
server validation, and order completion remain future work.

## Customer

- Phone + Telegram authentication
- Product catalog
- Product search
- Configurable products
- Persistent cart
- Checkout
- Online payment abstraction
- Pay on pickup
- Current orders
- Order history
- Repeat order
- Telegram notifications
- SignalR updates

## Employees

- Dashboard
- Reception board
- Kitchen board
- Pickup board
- Order details
- Real-time synchronization

## Administration

- Menu management
- Categories
- Product options
- Employees
- Roles
- Working hours
- Café settings
- Audit log

Success criteria:

- Customer can complete the full order journey.
- Employees process orders without page refresh.
- Administrator manages the entire system.

# Definition of Done

A feature is complete only if:

- Business rules implemented.
- API documented.
- UI implemented.
- Validation completed.
- Logging added.
- Authorization enforced.
- Real-time updates implemented where required.
- Tested manually.
- Documentation updated.
