# Mood Pickup Repository Instructions

Before making changes:

1. Read `docs/04_Development/13_Developer_Guide.md`.
2. Read the feature-specific documentation.
3. Keep changes inside the current sprint scope.
4. Do not introduce Clean Architecture, MediatR, repository abstractions, or Unit of Work.
5. Keep the backend as one ASP.NET Core Web API project with clear MVC-style folders.
6. Run relevant builds and tests before reporting completion.
7. Never claim success for commands that were not executed.
